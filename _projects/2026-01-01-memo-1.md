## Data

**Sources:** Synthetic top-of-book snapshots (1-second bars) and trade prints. Vendor adapters (e.g. Refinitiv Tick History, CME DataMine) are stubbed with the same interface — swap in real credentials to replicate on live data.

**Sampling:** Intraday, restricted to exchange hours. Session-open and close periods flagged separately to avoid microstructure noise.

**Known issues:**
- Synthetic data does not capture correlated spread widening during macro events — production data would require event masking.
- Timestamp alignment between trade prints and book snapshots requires sub-second precision; misalignment is a common source of look-ahead bias.
- Survivorship: only front-month contracts included; roll mechanics handled by generic continuation series.

---

## Methodology

**Feature construction:** Order-book imbalance (bid volume / (bid volume + ask volume) at top N levels), trade arrival rate, spread, and mid-price velocity. All features computed using only information available at time *t*, with no forward-fill that crosses the label window.

**Model:** Logistic regression and a shallow gradient-boosted tree for comparison. Linear model preferred for interpretability and resistance to overfitting on short samples.

**Validation design:**
- Walk-forward expanding window — training set grows chronologically; test set is always future data.
- Embargo period of 5 minutes between training and test windows to prevent label-bleed from overlapping returns.
- Hyperparameter selection uses inner-fold CV on the training set only; never touching the test set.

## Implementation Notes

**Latency:** Effective use of order-book signals requires sub-100ms execution latency. The methodology demonstration here is not latency-constrained (uses bar data), but a live system would need co-location and direct market access.

**Data freshness:** Book snapshots must arrive without queuing delays; staleness of even 1–2 seconds materially changes the signal.

**Explicitly excluded:** Proprietary parameterisations, live venue selection logic, and any firm-specific execution data.
