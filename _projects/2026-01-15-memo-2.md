## Abstract

**Research question:** Do publicly released macroeconomic indicators contain information that forecasts future asset returns across equities, fixed income, and commodities?

**Instrument universe:** Broad asset classes — equity indices, benchmark bond futures, commodity baskets — referenced by generic class labels; no proprietary identifiers.

**Dataset(s):** Public macro time series (PMI, CPI, inventory data, payrolls); synthetic market data for the pipeline demonstration.

**Primary result:** *Placeholder — e.g. PMI surprises show a statistically significant 5-day lead on commodity basket returns in expansion regimes, with the effect absent in contraction regimes.*

**Key caveat:** *Macro effects are regime-dependent and subject to data revisions; real-time vintage data is required for a proper production implementation.*

## Data

**Macro series:** PMI (manufacturing and services), CPI, non-farm payrolls, industrial production, crude oil and product inventories. All sourced from public providers (FRED, ONS, Eurostat). Point-in-time vintage data would be needed for a production implementation — revisions are handled here by using release-date-aligned vintage snapshots where available.

**Market data:** Synthetic daily bar data for the pipeline; adapter stubs for vendor OHLCV data exist with identical interfaces.

**Sampling:** Weekly frequency for the main analysis; monthly for slower macro series. Intraday event windows (±2 hours around release) are computed separately.

**Known issues:**
- Revision risk: macro releases are frequently revised; using final print instead of first print overstates forecastability.
- Publication lag: releases must be aligned to the *release date*, not the *reference period*, to avoid look-ahead bias.
- Holiday calendar variation across countries introduces sporadic missingness.

---

## Methodology

**Feature engineering:** Macro surprises (actual minus consensus forecast), directional surprises (sign only), and 12-month rates of change. Features are lagged by the publication delay to ensure no forward information is used.

**Model:** Predictive regression (OLS with Newey-West standard errors for serial dependence) as the baseline; gradient-boosted tree for nonlinear interactions. Regime segmentation uses a two-state HMM on realised volatility.

**Validation design:**
- Expanding-window walk-forward: train on years 1–N, test on year N+1, step forward.
- No cross-sectional random splits; all splits are chronological.
- Hyperparameters fixed from first training window; re-estimated only annually to avoid look-ahead.

## Implementation Notes

**Data freshness:** Macro releases are discrete events; the production pipeline must ingest release files within minutes of publication and propagate updated features to the signal layer.

**Holiday calendars:** Multi-country macro requires careful alignment across exchange holidays and data-provider conventions.

**Explicitly excluded:** Consensus forecast data sources (require vendor subscriptions), real-time vintage vintages, and live execution logic.
